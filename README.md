# 智能戳一戳插件 (Smart Poke Plugin)

> 本插件由 [Wenaixi](https://github.com/Wenaixi) 维护，是专为生产环境深度调优的高可用分支。

## 简介与定位

拟人化 QQ 戳一戳互动插件，支持根据人设随口回戳、文字调侃与贴表情回应。

- **插件目录**：`TAIY2020_smart_poke_plugin`
- **生效版本**：`v1.8.4`
- **开源许可证**：`MIT`

---

## 核心特性与本地深度调优

- 无损还原 QQ 原生个性化原话（发起者动作修饰 + 动词 + 麦麦个性后缀）
- 大模型思考中明确点明被触碰部位与搞笑设定，接梗调侃水准真人化
- 彻底拔除死板固定回复

---

## 指令与工具速查

### 常用指令 (Command)
- `(无独立斜杠命令，完全由 QQ 双击头像戳一戳事件原生驱动)`

### 大模型工具 (Tool)
- `@Tool("send_poke") - 大模型决策回戳工具`

---

## 快速配置

配置文件统一定位于插件根目录下的 `config.toml`。修改后重启或通过 WebUI 热重载即可生效。
